🎯 OVERVIEW
────────────────────────────────────────────────────────
Individual MTG card viewer with Scryfall API integration.
Search cards by name or set+number and view details.

📦 DISTRIBUTION
────────────────────────────────────────────────────────
✓ release/MTGCardViewerApp.exe    [Standalone EXE - 13.57 MB]
✓ No installation required
✓ No Python installation needed
✓ Just run and enjoy!

🚀 USAGE
────────────────────────────────────────────────────────

Option 1: Double-click Executable (Easiest)
  → release/MTGCardViewerApp.exe

Option 2: Run from Source
  → src/start_card_viewer.bat

Option 3: Python Development
  → cd src
  → python mtg_card_viewer.py

🔍 FEATURES
────────────────────────────────────────────────────────
✓ Search by card name (with auto-complete)
✓ Search by set + collector number
✓ High-resolution card images
✓ Complete card information (mana, type, stats, text)
✓ Direct link to Scryfall
✓ Dark mode UI
✓ Responsive design
✓ Real-time suggestions

⚙️ REQUIREMENTS
────────────────────────────────────────────────────────
✓ Windows 10/11
✓ Microsoft Edge WebView2 Runtime (usually pre-installed)
✓ Internet connection

🔧 REBUILD
────────────────────────────────────────────────────────
To rebuild the executable:
  → cd src
  → python -m pip install -r ..\requirements-build.txt
  → build_card_viewer_simple.bat
  
Result: release/MTGCardViewerApp.exe (updated)
