🎯 QUICK START
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Option 1: Windows Application (Double-click)
  → src\start_card_viewer.bat

Option 2: Command Line
  → Open PowerShell
  → cd src
  → python mtg_card_viewer.py

Option 3: Install & Run
  → python -m pip install -r requirements.txt
  → cd src
  → python mtg_card_viewer.py

💡 USAGE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Launch the application (see Quick Start)
2. Search by card name:
   - Type: "Lightning Bolt" or "稲妻"
   - Get auto-suggestions
   - Press Enter or click Search

3. Or search by set + collector number:
   - Set Code: "neo"
   - Number: "129"
   - Click Search

4. View card details:
   - High-res image
   - Full card stats
   - Complete rules text
   - Link to Scryfall
