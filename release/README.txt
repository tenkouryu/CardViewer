  MTG Card Viewer - Windows Executable
═══════════════════════════════════════════

🎮 HOW TO USE

1. Double-click MTGCardViewerApp.exe
2. Window opens automatically
3. Search for MTG cards by:
   - Card name (e.g., "Lightning Bolt")
   - Set + Collector # (e.g., "neo" + "129")
4. View detailed card info and images

❓ TROUBLESHOOTING

Q: "WebView2 Runtime not found" error
A: Install from:
   https://support.microsoft.com/answer/9140556

Q: Application won't start
A: Make sure Windows Defender isn't blocking it
   (Right-click → Properties → Unblock)

Q: Card not found
A: Check spelling or try the set + number search
   (Numbers are case-sensitive)
